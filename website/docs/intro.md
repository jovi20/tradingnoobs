# Trading Noobs 交易日志系统

> 一个全栈 Web 应用，用于记录、分析和复盘美股与加密货币交易。

![Dashboard Preview](https://img.shields.io/badge/Next.js-14-black?style=flat-square&logo=next.js) ![FastAPI](https://img.shields.io/badge/FastAPI-0.109-009688?style=flat-square&logo=fastapi) ![TypeScript](https://img.shields.io/badge/TypeScript-5.0-3178C6?style=flat-square&logo=typescript)

## 📖 项目简介

Trading Noobs 是一个专为交易者设计的现代化交易日志系统。它不仅仅是一个简单的记账工具，更是一个帮助你建立交易体系、分析交易心理、优化交易策略的私人助手。

通过集成 AI 智能分析、详细的数据看板和专业的复盘功能，Trading Noobs 致力于帮助每一位交易者从新手（Noob）成长为专业交易员。

## ✨ 核心功能

### 1. 🔐 安全认证与私密性
- **账户安全**：基于 JWT 的高安全认证体系。
- **数据隐私**：所有交易数据私有化部署，确保您的资金和策略只有您自己可见。

### 2. 📈 专业的交易记录
- **全生命周期管理**：完整记录开仓、建仓、平仓全过程。
- **心理与决策记录**：不仅记录价格，更记录交易时的情绪（FOMO、犹豫、自信等）和决策依据。
- **智能资产分类**：自动识别并分类您的资产（现货、杠杆、期货、期权、加密货币等）。

### 3. 📊 数据可视化看板
- **盈亏分析**：实时的 P&L 曲线，直观展示资金增长趋势。
- **核心指标**：自动计算胜率、盈亏比（Risk/Reward Ratio）、最大回撤等关键指标。
- **日历视图**：以日历形式回顾每日盈亏，快速定位高光时刻和回撤日。

### 4. 📝 深度复盘系统
- **Markdown 笔记**：支持富文本格式的复盘笔记，记录市场分析和交易感悟。
- **每日/周总结**：强制性的周期性总结机制，帮助您养成良好的复盘习惯。
- **AI 洞察报告**：利用 LLM（大语言模型）自动生成周报，根据您的交易记录提供类似"芒格"风格的毒舌点评与建议。

### 5. 🎯 策略管理
- **策略库**：定义并管理您的交易策略。
- **绩效归因**：将每一笔交易关联到特定策略，统计不同策略的胜率和收益，帮您筛选出最适合自己的交易系统。

### 6. 🛠️ 实用工具
- **实时行情**：集成多渠道（美股、港股、A股、Crypto）实时行情数据。
- **多主题支持**：日间/夜间模式，适应不同光照环境。
- **移动端适配**：随时随地通过手机查看和记录交易。

## 🛠️ 技术架构

本项目采用现代化全栈架构，确保高性能与良好的用户体验：

| 层级 | 技术栈 |
|------|------|
| **前端** | Next.js 14, TypeScript, Tailwind CSS, Recharts |
| **后端** | FastAPI, SQLAlchemy, Pydantic |
| **数据库** | PostgreSQL (生产环境) / SQLite (开发环境) |
| **部署** | Docker, Caddy Server |
